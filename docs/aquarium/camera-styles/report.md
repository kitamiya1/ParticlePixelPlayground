# 第 2 段階：カメラの方式（改良型三人称・肩越し / 一人称・自由追従）

カニの姿や動きを眺める楽しさを大切に、三人称を基本にしたまま、狭い所・地形の中でもカニと進む向きを見失わないようにする。
冒険カメラの方式を 4 つ切り替えて比べられるようにした（ガラス越し・箱庭はそのまま）。

| 方式 | 既定 | 中身 |
| --- | :---: | --- |
| 従来（classic） | | 変更前の冒険カメラそのまま（比較用） |
| **三人称（tps）** | ✅ | 改良型三人称（下） |
| 肩越し・一人称（close） | | いつでも切り替え（C キー・カメラのボタンの長押し・ゲームパッドの左スティック押し込み） |
| 自由追従（free） | | 地形でカメラを止めない。カメラとカニの間だけ抜く |

設定は右上「🔊 音と設定」→「カメラ（冒険）」（localStorage `ppp-aquarium:ui` の `camStyle`）。

## A：改良型三人称（`AquaCamera.ts`）
- **腕の最短 1.15**：障害物で腕が縮むとき、まず見る角度を 0.12 ずつ（最大 0.84）上げて腕が伸びる角度を探す（`raise`。平滑化：
  上げるのは速く、戻すのはゆっくり。プレイヤーの yaw / pitch は変えない）。それでも 1.15 に届かなければ 1.15 で止め、
  カメラとカニの間の物を**砂も含めて**描画で抜く（`cutThrough`）。抜くのをやめるのは、カメラがふつうに置ける距離まで
  なめらかに戻ってから（やめた瞬間に手前へ飛ばない）。
- **カメラの位置の動きの上限**（`smoothPose`：カニの動き + 4.5 / 秒）を、掘った穴のそば以外でも使う。
- 水面の高さを避けるときの上下の側を、カニが水面をまたいでも一気に入れ替えない（0.2 秒ほどで移す）。
- 地下のトンネル（従来の近い視点）・天井・壁の扱いは従来どおり（トンネルの中では上の最短の処理を弱める）。
- 地形の中から見た裏面は、断面の暗い土の色で塗る（`AquariumRenderer` の `uCap`。抜いている間だけ両面を描く）。

## B：肩越し・一人称（close）
- 体の上（ふだんは真上、壁・天井では面の外向き。平滑化して急に回らない）0.3 の所から、見る向きの水平な後ろへ最大 0.2 引き、
  前を 0.42 rad 見下ろす。画角 78°。甲羅は近いほどディザで透け（従来の `crabFade`）、ハサミは半分だけ透けるので、
  ハサミと挟んだ物が視界の下に入る。
- 見る向きはプレイヤーの yaw / pitch（三人称と同じ値）なので、カニの姿勢でカメラは傾かない・回らない。
- 入れる・戻すは 0.25 秒ほどで混ぜる（`closeW`）。戻すと元の三人称の位置・向きへなめらかに戻る（三人称の値はそのまま持っている）。
- 切り替え：PC `C`、スマホ カメラのボタンを 0.42 秒長押し（短く押して離すと従来どおり 冒険 → ガラス越し → 箱庭）、
  ゲームパッド 左スティック押し込み。ガラス越し・箱庭のときは冒険カメラへ戻してから切り替える。

## C：自由追従（free）
- 注視点から見る向きへ zoom の所にそのまま置く（地面の下・岩や流木の中にも入る。部屋の範囲と水面の高さだけ守る）。
- カメラとカニの間を円すい（カニの位置で半径 0.62）で抜く。範囲は砂（底床・掘った区画・小石・巣穴）・岩・流木・枠・家具・水草。
- 地形の中から見た裏面（掘っていない砂・岩の中）は断面の暗い色で塗る。中身の無い穴・描画の欠けは見えない。

### 透過の方式の比較
| 方式 | 見た目 | 現在の描画構造との相性 | 処理負荷 |
| --- | --- | --- | --- |
| **円すいのディザ抜き + 裏面を断面の色**（採用） | 抜いた縁がディザで柔らかい。地中からは暗い土の中に丸い窓が開き、その先にカニ | 既存の `OCCLUDER_CUT`（薄い物の抜き）を砂のマテリアルへ広げるだけ。区画の作り直し・当たり判定と無関係 | 抜いている間だけ地形を両面で描く。計測で差は測定の揺れの範囲（下） |
| 近い面で切る（クリッピング平面） | 断面がまっすぐ。カニの手前のすべてが消え、周りの景色まで消える | 平面 1 枚は簡単だが、トンネルの曲がりでカニの横の壁も消える | 軽い |
| SDF の断面を描く（光線を進めて断面を塗る） | 断面に砂の層・空洞が正確に出る | 描画は三角形 + 円盤で、SDF を GPU に持っていない（掘った形はCPU 側の距離関数）。持たせるには 3D テクスチャ化が要る | 重い（iPhone で画面全体の光線の行進は厳しい） |

- 「カニが見える」= カメラとカニの体の中心の間に固体が無い、または描画で抜いている割合。瞬間移動した直後の 40 フレームは数えない。
- 調整の途中で見つけて直した揺れ：腕の最短で抜き始めた瞬間に動きの上限が外れて 0.58 飛んだ（抜いている間も上限を使うよう直した）、
  トンネルへ入った瞬間に上げていた角度が 1 フレームで戻って 3.8° 回った（ゆっくり戻すよう直した）、肩越しで壁へ移る瞬間に 0.4〜0.5 飛んだ（体の上の向きを平滑化）。
- 天井歩きの回帰（`ceiling_test.js`）：洞窟のトンネルのカメラの 1 フレームの最大の動き 0.33 → 0.08。ほかの 5 か所は同等。
  倒木の中で押したまま離れる場面は、腕の最短で抜いている間カメラが流木の中に入る（想定どおり。抜いて描くので視界は遮られない）。
- 性能（`tools/perf_quick.js`、方式ごとに交互に 2 回）：更新 + 描画の命令 1.2〜1.6 ms、実際のフレーム間隔 15〜16 ms で、方式による差は無い。
  GPU の時間は別に測れていない（自由追従で地形の中にいる間は両面を描くので、iPhone で重くならないかは実機で確かめたい）。
- 保存・復元（`save_roundtrip_quick.js`）OK。本番ビルド OK。

## 未確認・残る問題
- **iPhone 実機・実際のゲームパッドは未確認**（長押しの長さ 0.42 秒・左スティック押し込みの押しやすさ）。
- 肩越し・一人称は、天井に逆さで張り付いている間、カメラが体の下側（面の外向き）に来るので、カニの体が視界の上に被る。
- 自由追従で地形の中にいると、周りは暗い断面の色一色になる（窓の先のカニだけが見える）。地中の層・空洞の表現は SDF の断面描画を
  入れない限り出ない。
- 天井歩きの「スティック↑」の矢印（第 1 段階で外した）の代わりの、進む向きの分かりやすさは第 4 段階の歩き方と合わせて見直す。
