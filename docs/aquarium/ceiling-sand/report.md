## 1. 天井歩き

### 操作感
- 壁に張り付いたまま押し続けると、張り出し → 天井（完全な逆さ）→ 反対側の壁 → 床と、止まらずに回り込む。押している向きは
  途中で反転しない（スティックの前・右を「面に貼り付けた向き」として持ち、面の向きが変わるたびに同じ回転で回すため）。
- スティックを離すとその場で止まる（離した瞬間から 0.07〜0.08 だけ滑って止まる。重力・浮力・水流は効かない）。
- 天井の上では、離したあとにもう一度押すと「画面の前 = カメラから離れる向き、右 = 画面の右」で前後左右へ歩く（約 1.3 /秒）。
  回り込んだ直後に押したままのときだけ、前が「回り込んだ向きの続き」（多くはカメラへ近づく向き）になる。
- 跳んで・泳いで天井に触れ、スティックかジャンプを押していると張り付く（洞窟の天井へジャンプ → 約 0.1 秒で張り付く）。
  泳いでいる間はジャンプの長押しだけでは張り付かない（遊泳が天井で止まらないように）。
- ジャンプで離れると真下へ押し出され、体の前を軸に転がって起き上がりながら落ちる・沈む（約 0.5 秒で正立）。
  水中で押したままなら遊泳へ移る。天井から離れた直後 0.6 秒は張り付かない。
- 体と脚は「上 = 面の法線・前 = 体の前」の座標軸で向く（逆さでも体が急に回らない。1 フレームの体の回転は最大 12〜17°＝張り付く瞬間の傾き）。
  脚は従来の壁登りと同じく面へ押し付けて広げ、止まっている間はゆっくり踏ん張り直す。
- カメラは傾けない（画面の上下は反転しない）。天井に張り付くと、注視点を面から空いている所まで（最大 0.85）離し、見る先をカニへ寄せる
  （カニの下・横から見上げる）。掘ったトンネルの中では近い視点（頭の上）を弱め、天井の逆さのカニを後ろ下から見る。
- ガラス・アクリル・管・設備には張り付かない（従来どおり、登れる物だけの距離関数 `climbSolid`）。

### 確かめた場所（`docs/aquarium/tools/ceiling_test.js`、開発サーバー）

- 左右へ動かすと、狭いトンネル・倒木の中では横の壁へ回り込んで床へ戻る（壁・天井・壁と 360° 連続でつながる。倒木の中で同じ向きを
  押し続けると、筒の内側をぐるりと回り続ける）。
- 90° を超える回り込み：岩の柱の根元（張り出し約 130°）から頂上へ、中空の倒木の外側の下の張り出しから上へ（凸の面）。
- 凹凸のある面・複数の面の角：洞窟・崖の岩（でこぼこのノイズ）、掘ったトンネルの平らな床と壁の角、壁と天井の角を確認。
- 空中から：洞窟でジャンプして天井に張り付く（1 回）、そのまま天井を前へ 1.32 進む。
- ガラス（手前・陸地の右）・縦の管（アクリル）へ押し付けても張り付かない（張り付き 0 回）。
- 既存の壁登りの検証（`climb_test.js`）：登り直し 10 地点のうち掘り抜けた 7 地点すべてで登り直せた（残り 3 地点は岩・岩・流木に当たって
  掘り抜けない：main と同じ）、岩の垂直面で止まる、ガラス・管・アクリルに張り付かない、は従来どおり。
  「地下の壁を横へ」は、従来は壁で止まったが、天井まで回り込むようになった（意図した変化）。
- 比較画像：同じ場所・同じ入力で、main は張り出し約 135°（法線の y ≈ −0.7）で止まり、このブランチは天井（−0.98〜−0.99）まで回り込む。

## 2. 砂の回収と再配置

### 操作
| | PC | スマホ |
| --- | --- | --- |
| 掘る ↔ 盛る | <kbd>G</kbd> | 「掘る」ボタンの上の小さな切り替え（掘る｜盛る。下の帯が手持ちの砂の量） |
| 実行 | <kbd>F</kbd> 長押し（マウスをずらす・右ドラッグで狙う。掘ると同じ） | 「掘る」ボタン（盛るのときは緑の「盛る」。押したまま指をずらして狙う） |
| 手持ちの砂 | 左上の「砂」の帯と「n / 80」（満杯なら「満杯」）、いまの道具 | 同じ |
| 盛れる所 | 黄緑の輪を面の上へ寝かせて表示（置く砂山の大きさ）。盛れないときは赤い小さな輪と、左上に「盛れない：理由」（砂が足りない・ガラスのそば・配管のそば・宝物のそば・近すぎる・届かない） | 同じ |

- 盛る照準は、ずらしていなければ浅い斜め下（体から 0.8 ほど先）。押し続けると 0.17 秒ごとに砂山が大きくなり（半径 0.2 → 0.42）、
  いっぱいになると上へ積む（高くなる）。カニ・仲間に近づきすぎると「近すぎる」で止まる（少し下がると続けられる）。
- 盛った砂は歩ける（坂として登る：0.58 上がった）・張り付いて登れる・掘り直せる（使った 0.375 がそのまま戻り、砂山が消えた）。
- 掘ったトンネルの中（床・突き当たり）にも盛れる（6 個のうち 5 個が、掘った空洞の中に盛られて砂に戻った）。
- 盛る所を全部の物（岩・流木を含む）の面で選ぶので、岩・流木の上にも砂を載せられる。ガラス・アクリル・管・底板の上には盛らない。

### 砂の量
- 手に入る砂 = 実際に取り除いた体積（編集の前後の形を格子 0.12 で比べる）。容量 4（画面では 1 杯 = 0.05 → 80 杯）。
- 空振り（照準の先に何も無い）：0。同じ所で掘り続ける：最初の約 1 秒で 1.45 増え、その後 1.5 秒続けても 0（空洞が太りきると増えない）。
- 前へ掘り進めると増え続け、容量で止まる（超えた分は捨てる。試験では 5.07 を捨てた）。岩に当たる・掘った穴の中を太らせるだけ、では増えない。
- 盛ると足した体積だけ減る（高さ 0.81 の砂山で 0.375 = 約 7.5 杯）。足りなければ盛れない（「砂が足りない」）。
- 厳密な質量保存ではない：格子による誤差が数 %、盛った砂のなじませ（元の地面との丸み）の分も数える。

### 地形の SDF と区画の更新（`AquariumDig.ts`）
- 掘った空洞（平らな床のカプセル）と盛った砂（球）を **1 つの並び `prims` に編集した順で** 持つ。各物に種類（`fill`）と層（`layer`）。
  層は「種類が変わるたびに 1 増える番号」で、足したときに決まる（あとで太らせても変わらない）。
- 砂の値 = 元の砂（高さ場の距離）に、区画の一覧（番号順）の層を順に当てる（`compose`）：
  掘った層は層の中の空洞を滑らかに合わせ（従来の `unionK`）、ガラス際の傾き（`GLASS_SLOPE`）・打ち切り（`clip`）・`carveSand`（膜を開ける・
  縁を少し削る）を従来どおり当てる。盛った層は盛った砂を合わせて、打ち切り（底の項を除いた `fillClip`）の外だけ `smin(d, f, 0.22)` で足す。
  → 掘った穴へ盛る（後の盛った層が勝つ）・盛った砂を掘る（後の掘った層が勝つ）を、どちらの順でも正しく表せる。
- **掘るだけ（層が 1 つ）のときは従来とまったく同じ値**：同じトンネルを main とこのブランチで掘ったとき、見た目と当たり判定の光線の検査の
  結果が一致（不一致の光線 16 本と、その位置・値まで同じ）。版 1 の保存データの復元でも、区画ごとの三角形・当たり判定の値が完全に一致。
- 区画ごとの登録・作り直しの印（外接箱 + 0.25）・2 つの版（snap で作り直し → 全区画そろったら一斉に差し替えて commit）は、掘るときと同じ `add` /
  `modify` を通す。盛った砂のある区画は、Surface Nets の縦の範囲を砂山の上まで延ばす（`chunkMaxY`）。地表より上を飛ばす近道
  （`meshValue`）は、区画の盛った砂のいちばん高い所より上だけにした。
- 見た目：盛った面は、その場所の地表の色を盛りたての砂の色へ寄せる（高く積もるほど）。ガラス際の断面の、元の地表より上の部分も同じ色。
  根元が 0.15 以上埋まった水草の円盤・深く埋まった小石は隠す。
- 保護：盛った砂は、ガラスの面の外 0.12 より外・縦の管の区画のまわり 0.3・発見物（宝物・巣穴）のまわりにはできない（打ち切り）。
  盛る所の中心がそこに近ければ盛らない。カニの体・仲間（見つけた後）の体から 0.1 以上離す（砂山の大きさを抑える）。
- 量の測定は 1 回の編集で数 ms（スマホ相当では数十 ms）かかるため、フレームに分けて 1 フレーム 1.5 ms まで（次の編集・保存の前には測り終える）。

## 6. 残る問題・実機で確かめたいこと

1. **天井へ回り込んだ直後の「前」**：押したまま回り込むと、天井の上での前は「回り込んだ向きの続き」（多くはカメラへ近づく＝画面の下）のまま。
   離して押し直すと画面の前に戻る。スマホのスティックで違和感がないか、実機で確かめたい。
2. **筒の中で押し続けると回り続ける**：倒木・狭いトンネルの中で同じ向きを押し続けると、壁 → 天井 → 壁 → 床 → 壁…と回る（意図した動き）。
3. **狭い所のカメラ**：天井のカニを下から見る構図は、洞窟では良いが、掘ったトンネル・倒木の中ではカニが画面の上の方に大きく映る。縦持ちで
   左上の表示と重なることがある。
4. **盛る照準の輪が小さい**：高解像度のスマホでは点が細かい。置ける所の表示が十分見えるか、実機で確かめたい（必要なら太くする）。
5. **砂山の形**：球をなじませたドーム。続けて盛るとまっすぐ上へ積むので、狙った所へ「坂」を伸ばすには少しずつ前へ進みながら盛る必要がある。
   カニに近づくと「近すぎる」で止まる（下がると続けられる）。
6. **砂の量は数フレーム遅れて増減する**（測る処理を分けたため。保存の前には必ず測り終える）。
7. **自分を閉じ込められる**：トンネルの入口を盛った砂で塞げる（掘れば出られる）。
8. **盛った砂の光**：焼き込んだ日照の格子は作り直さないので、砂山は影を落とさない（砂山の面の明るさは周りの光で決める）。
9. 既存（main でも同じ）：ガラスへ押し付けると状態が「ジャンプ / 沈降」に揺れる（ガラス際の砂が少し下がっているため）。
   667×375 の横画面で「調べる」ボタンと「？」が重なる。トンネルの入口・ガラス際の巣穴の縁で、面をかすめる光線の見た目と当たり判定のずれ。
10. iPhone の Safari そのものではなく Chromium のスマホの模擬で確かめた（WebKit の実機は未確認）。
