# 第 5 段階：石の軽量化と環境との相互作用

## 実装

### 小石・貝殻・重い石（`AquaGrab.ts` の `PROP_KIND`）
| 種類 | 重さ | 水中で沈む強さ | 水の抵抗 | 摩擦 |
| --- | --- | --- | --- | --- |
| 貝殻 | 0.12 → **0.08** | 2.4 → **2.0** | 3.0 → 3.2 | 0.45 → 0.4 |
| 小石 | 0.35 → **0.22** | 4.6 → **3.8** | 1.3 → 1.5 | 0.6 → 0.5 |
| 重い石 | 1.2 → **0.8** | 7.0 → **6.4** | 1.0 → 1.2 | 0.4 → 0.35 |

- 景色の小石（約 520 個）の重さは小石の値 × 体積なので、同じ割合で軽くなる（大きさの違いは残る）。
- 重さによる歩きの遅れを弱めた（速さの上限 = 1 − 0.45 × 張り² → 1 − 0.28 × 張り²）。物に引かれる反作用も弱めた（カニの重さ 0.6 → 0.85）。
- 重い石は水中ならやっと持ち上がる（重さ × 沈む強さ 5.1 < 握る力 8）。陸では持ち上がらない。

### 水草を挟む・引く・抜く・ちぎる（`AquaCatch.ts` の `PlantGrab`・`WeedPieces`、`AquaPlants.ts`）
- 茎・葉を直接挟める（第 3 段階の植物の表の、茎の線にいちばん近い点。巣穴の触角のような「遠くから挟める」補正は無し）。
- 挟んで引くと、植物はその高さで鋏の方へしなる（第 3 段階のばね。上限まで）。上限を越えて引いた分が張力になり、ばねの力としてカニへ返る
  （根が張っている植物は引き戻す）。
- 張力が種類ごとの強さを 0.35 秒越えると：根元から 0.16（テープ状の葉）/ 0.2（有茎草）より高い所を挟んでいれば**そこで切れ**、
  低い所なら**根元から抜ける**（砂が舞う・短い音）。シダ・葉の広い草は根が強く（抜ける張力 7.2 / 7.6、握る力の 0.95 倍に近い）、
  急に強く引くとハサミが滑る。

  | 種類 | 抜ける張力 | 切れる張力 |
  | --- | ---: | ---: |
  | テープ状の葉 | 4.6 | 3.6 |
  | 有茎草 | 5.4 | 4.6 |
  | シダ | 7.2 | （切れない） |
  | 葉の広い草 | 7.6 | （切れない） |
  | 汀線の草 | 3.4 | （切れない） |

- 抜けた・切れた部分は**かけら**になり、そのまま挟んでいる（鋏の状態の更新が終わってから渡す）。かけら = 元の円盤を写した円盤の集まり
  （`SurfelRenderer.addPiece`。元の円盤は隠す）+ 軽い物理の物（`PropKind 'weed'`：重さ 0.02〜0.12、沈む強さ 0.45、水の抵抗 4.5）。
  運べる・離すとゆっくり漂って沈む。挟んで運ぶかけらも水草を押し分ける。かけらは 8 個まで残し、古いものから片づける。
- 長い葉は、つかんだ所から 1.0 までをかけらにする（それより先は流れて消える。持って歩いても画面を覆わない）。

### エビ・小魚を捕まえる（`AquaCatch.ts` の `LifeGrab`、`AquaLife.ts`）
- 近づくと逃げる（従来）。ただし**気づくまでの間**（小魚 0.35 秒・エビ 0.28 秒）があり、**ゆっくり忍び寄る**（速さ 0.7 未満）と
  逃げ始める距離が短い（小魚 1.9 → 0.9、エビ 1.15 → 0.55）。その間にハサミが届けば挟める。
- 挟まれた生き物は体を動かして抵抗する：エビは 0.45〜1.0 秒おきに尾で強く跳ね（後ろ・上へ、0.07 秒）、小魚は尾を小刻みに振り続けて
  0.25〜0.6 秒おきに身をよじる。その力がハサミを越えると滑ってハサミから逃れる（巣穴の生き物と同じ滑りの仕組み）。
  握られる力：エビ 4.2・小魚 4.0（巣穴の生き物・物は 8）。
- 離す・逃れると、その勢いのまま逃げる（エビは跳ねる・小魚は怖がって速く泳ぐ）。その後は従来の動きへ戻る。
- 挟まれている間は地形・ガラス・管にめり込ませない（距離関数で押し出す）。
- 名前・「挟める」は常には出さない（第 1 段階の「案内を出す」のときだけ、左上・詳細に名前）。

| 物 | 変更前（公開版） | 変更後 |
| --- | ---: | ---: |
| 小石 | 0.63 | **0.78〜0.82** |

### エビ・小魚（生き物の正面 0.32 に置いて挟む → 1.5 秒持つ）
| 生き物 | 挟めた | 逃れた | 暴れた回数 | めり込んだフレーム |
| --- | ---: | ---: | ---: | ---: |
| エビ（10 回） | 4 | 0（握る力 0.6 倍のとき） → 調整後 0.52 倍 | 14 | 0 |
| 小魚（10 回） | 2 | 3 | 5 | 0 |

- 握る力 0.42 倍では、挟めた 5 回のほとんどで逃れた（暴れが強すぎる）→ 0.6 倍で逃れない → 間の 0.52 倍にした（調整後の数は未計測）。
- 回帰：ゲームパッド・左右のハサミ・左の鋏で巣穴を引く・スポン（`pad_audio_test.js`）すべて ok、`claw_touch_test.js` 8/8、
  保存・復元 OK（かけら・挟んだ生き物は保存しない）。本番ビルド OK。
- 性能（交互に 2 回）：更新 + 描画の命令 公開版 1.46〜1.52 / 変更後 1.53〜1.74 ms。フレーム間隔の差は無い。

## 未確認・残る問題
- **iPhone 実機・実際のゲームパッドは未確認**。
- 水草は張力が強さを越えるとすぐ（0.35 秒）切れる・抜けるので、「しなる」のを見る間が短い。強さの値は実際に遊んで調整したい。
- かけらの当たりは小さな楕円体（最大 0.14）なので、長い葉のかけらは見た目より狭い所に当たる（砂に少し埋まって見えることがある）。
- 小魚は水中の高い所を泳ぐので、底を歩くカニからはなかなか届かない（遊泳して近づく）。
- 植物を抜いた・切った状態は保存しない（読み込み直すと元に戻る）。
