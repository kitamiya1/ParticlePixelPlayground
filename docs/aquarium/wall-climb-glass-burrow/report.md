## 1. 操作と対応する材質

| 操作 | PC | スマホ |
| --- | --- | --- |
| 張り付く | 壁へ向かって W A S D を押し続ける（約 0.1 秒） | 仮想スティックを壁へ倒し続ける |
| 登る / 降りる / 横へ | 壁へ向かう向き = 上、壁から離れる向き = 下、壁に沿う向き = 横（カメラ基準の入力のまま） | 同じ |
| 止まる | 離すとその場で止まる（滑り落ちない） | スティックを離す |
| 離れる | Space（面から跳んで離れる。水中で押し続ければ遊泳へ） / 降りて床へ着くと歩きに戻る / 掘る（F）で離す | ジャンプ / 掘る |
| 走る | Shift で速く登る | ダッシュ |

- 登れる：砂・土（掘ったトンネルの壁を含む）・岩・流木
- 登れない：ガラス・濾過槽のアクリル・排水管 / 給水管（滑らかな管）・底板・水槽台・部屋の家具
- 壁登りは水槽の中だけ（濾過槽・水槽台・部屋・管の中では従来どおり）

カメラは V キー / 画面の「カメラ」で 冒険 → **ガラス越し** → 箱庭 → 冒険 と切り替わる（ガラス越しが新しい）。

## 2. 壁登りの実装方式

### 登れる面の見分け方（`AquariumWorld.climbSolid`）

`contactSolid` は「全部の物の距離の min」なので、何に触れているかが分からない。そこで **登れる物だけの距離関数**
`climbSolid` を別に作った：水槽の中身 `solid`（砂の高さ場 − 掘った空洞・岩・流木）から、縦の管の柱（外径の円柱）を
抜いたもの。ガラス・アクリル・管・設備は入っていない。

- 張り付くのは `climbSolid` が体の半径 + 0.05 以内で、その面が床とみなせない急な面のときだけ。ガラスへ押し付けても、
  `climbSolid` は足もとの砂（上向き＝床）までの距離のままなので張り付かない（ガラスと砂が接する所の誤判定が起きない）。
- 押し戻し（当たり判定）は従来どおり `contactSolid`。`climbSolid` は「いま触れている面が登れるか」とその向きにだけ使う。
- 表示・検証用に `surfaceMaterial`（いちばん近い物の材質）を追加。

### 動き（`CrabController`）

- 張り付く：移動入力が壁へ向いていて（内積 0.35 以上）、面の法線の y が床の下限（0.55、掘った穴の中は 0.4）より小さく、
  0.1 秒続いたら。面の向きは体の中心から入力の向きへ 0.1 進めた所で測る（床と壁の隅で壁の側を選ぶ）。
- 張り付いている間（`climbMove`）：重力・浮力・水流を止め、入力を面に沿う向きへ写す。動いたあと登れる面から体の半径の
  所へ吸着（角を回り込む・凹凸に沿う）し、ほかの物は `contactSolid` で押し戻す。体の傾き `climbN` は平滑化して `groundN` へ。
- 終わり：緩い面（法線の y > 0.74）で歩きへ、面を失ったら（半径 + 0.12 より離れた）落下、ジャンプで跳んで離れる、掘る・
  管・水槽の外で離す。
- 張り出し：法線の y −0.8 より下向きの所へは進まない（すでに張り出していれば緩くなる向きへは進める。岩の根元は楕円体の
  下側がくびれて 130° ほど張り出している）。押し続けても進めなければ、**縁を回り込む道**（`findMantle`：面から離れる →
  上へ → 壁の側へ戻る、の折れ線で、途中が体の入る隙間）をたどる。見つからなければ面から小さく跳んで離れる。
  歩いていて急な面の下のくぼみ（掘った穴の出口の縁）で進めないときも同じ道を探す。
- 体の向き：面に沿った速度を、面を床に起こした座標へ戻して（`toSurfaceLocal`）横歩きの向きを決める。脚の動きの速度も同じ。

### 見た目（`CrabRig`）とカメラ

- 体を面の向きへ傾け、根を球の中心から「体の上」の逆へ半径だけ下げた所に置く（平らな床では従来と同じ）。
- 進んでいる間は面に沿った足運び、止まっている間は脚を広げて足先を面へ押し付け、ゆっくり踏ん張り直す。鋏は前へ伸ばして面をつかむ。
- 冒険カメラは壁登り中、注視点を面の外向きへ 0.3 離す（腕が壁に食い込んで壁しか見えなくなるのを防ぐ）。

## 3. 巣穴観察の実装方式

### ガラス際まで掘る（`AquariumDig`）

- `DIG.glassClip` 0.7 → **−0.12**：空洞をガラスの内側の面の外（ガラスの厚みの中）まで作れる。ガラス自体は
  `contactSolid` の当たり判定で残るので削れず、越えられない。底（`floorClip`）・管の区画・発見物の保護は変えていない。
- ガラス際の薄い膜：空洞の端とガラスの面の間に格子（0.1）より薄い砂が残ると、見た目では穴がガラスまで抜けているのに
  当たり判定には膜が残る。既存の `FILM`（地表との膜）と同じ考え方で、膜の厚さが 0.12 より薄ければ開ける（`glassFilm`。
  当たり判定と見た目の両方）。

### ガラス際の断面を区画ごとに作り直す（`AquariumBuild`・`AquariumDigFx`）

- 初期の断面（`buildTerrain` の 4 辺の帯）を、帯の真ん中が入る区画（ガラスに接する区画）の三角形の範囲へ入れた。
  掘った区画を隠すと（既存の `hideTerrainChunk`）、そこの断面も一緒に隠れる。
- ガラスに接する区画の `buildDigChunk` は、砂の距離を **ガラスの内側の面（0.015 内側）で切って**（`max(砂, 面)`）、
  水槽の底の少し下から Surface Nets で三角形にする。穴がガラスまで届いた所は面に穴が開き、周りには地層の断面が残る。
  断面の頂点は初期の断面と同じ色・向き・明るさ。トンネルの床・壁・天井と断面は同じ距離関数から作るのでつながる。
- 作り直しは既存の方式のまま：汚れた区画だけを、カニに近い順に時間の上限まで作り、全部できたら一斉に差し替えて
  同じ瞬間に当たり判定へ入れる（`snapshot` / `commit`）。水槽全体は作り直さない。
- 速さ：ガラスに接する区画は断面が水槽の底まであるので重い。空洞のいちばん低い所より 0.6 下は空洞を調べずに決める。

### ガラス越しのカメラ（`AquaCamera.observePose`）

- 注視点（カニ）から見る向き（yaw / pitch）へ進み、ガラスの外面を越えた所から zoom（0.35〜14）離れた所に置く。
  向きを回すと、そちらのガラスの外へ回り込む。カメラは常に水槽の外なので、砂・ガラスにめり込まない。
  底板より上・部屋の中に留め、水面の高さちょうどは避ける。入ったときは、いちばん近いガラスの正面から見る。
- 移動の基準はこのカメラの向き（スティックの上 = 画面の奥）。カニが水槽の外へ出たら、戻るまで冒険カメラと同じ。
- カニとの間に砂・岩があれば「カニ」の印を出す（トンネルの奥へ入ったとき）。
- ガラスの映り込み（フレネル・斜めの帯）をこのカメラの間だけ 25% に弱める（`uGlassClear`）。地下の暗さは変えない。
- カニの接地影は上向きの面だけに落とす（`BLOB_UP`。真下へ投影すると断面に縦の帯ができた）。共有の
  `LIGHTING_CHUNK` に define で入れたので、方式 A〜F（define なし）の結果は変わらない。

## 7. 残っている問題

1. **ガラスの 1 マス手前で止まった穴の突き当たり**：空洞の端とガラスの間に格子 1 点だけの砂の板が残る所で、Surface Nets の
   板の縁に小さな抜け（約 0.05）ができる。既存の検査で 49 本（0.13%）、外からの検査で 0〜2 本。当たり判定はガラスなので
   カニの動きには影響しない。直すなら、ガラス際は格子 2 マスより薄い板を開ける（試した 0.22 では減らなかった。板の厚みが
   切り替わる所に必ず 1 点の板ができる）か、断面の帯を穴の形で切る別の作り方。
2. **ガラス際を掘っている最中の負荷**：上の表のとおり作り直しが 3 割重い。断面の下の部分（穴より下）を初期の帯から残し、
   穴の高さの帯だけ作り直す（区画の範囲を高さで 2 つに分ける）と減らせる。
3. 掘ったトンネルの横の壁に張り付くと、天井の近く（約 135°）まで回り込んで逆さに近い姿勢になる。陸地のトンネルでは一度離れた。
4. 縁を回り込む動き（`findMantle`）は折れ線を一定の速さでたどる。専用の脚の動きは無い（登る足運びのまま）。
5. カメラ：中空の倒木を越えて向こう側へ落ちるとき 1 フレームに 0.88 寄る（既存の遮蔽の処理。水中で跳んで越えても同じ）。
   壁登りで水面の高さを横切るときの 0.45 も既存の切り替え。
6. 陸地側の断面の前に、ガラスの水面の線（メニスカス）が横切って見える（従来から。断面の前に水は無い）。

## 8. 見つけた食い違い（文書・コメントとコード）

1. `AquaCamera.ts` の冒頭は「2 種類のカメラ」だった（今回 3 種類にしたので直した）。
2. `AquariumWorld.ts` の流木 `log` のコメントは「陸地から水中へ斜めに入る流木（上を歩いて上陸・入水できる）」だが、
   枝の軸はほとんどの所で地表（高さ場）より下にあり、砂に埋まっている（x 4〜12 の軸の高さ 4.6〜7.0 に対して地表 5.7〜6.7）。
   今回は触っていない。
3. `dig_config.json`・`route_config.json` の保存先（`dir`）が過去の報告のフォルダ（`fix-mobile-camera-terrain`）のままで、
   そのまま実行すると過去の報告の画像を上書きする（今回は設定を差し替えて実行した）。
4. `mesh_check.js` は「水槽の外に当たった光線を除く」としていたが、ガラス際まで掘れるようになって、ガラスの面のすぐ内側
   （断面より外）に当たる光線を数えてしまうようになった。0.05 以内を `glassZone` として別に数えるようにした。
5. カニの根の位置は、坂でも「球の中心の真下」だった（体は坂へ傾くのに、足は坂から浮く）。面の側へ下げるようにした
   （平らな床では従来と同じ）。
6. 共有の照明（`LIGHTING_CHUNK`）の接地影は真下へ投影するので、縦の面（岩の側面・断面）に縦の帯ができていた。水槽だけ
   `BLOB_UP` で上向きの面に限った。
7. 変更前は、ガラス際 0.7 の掘れない帯に当たると照準に「掘れない：ガラス」と出ていた（実際にはガラスより手前の砂）。
   今はガラスに当たったときだけ。
