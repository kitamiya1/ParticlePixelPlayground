# 引っこ抜き 2.0：ハサミで直接挟んで引っ張る

スナモグリの引っこ抜きを「巣穴のそばで E 長押し（約 0.6 秒）」から、「見えている触角をカニのハサミで挟み、挟んだまま動いて引っ張る」に変えた。
ブランチ `feat/aquarium-burrow-pull`（`origin/main` = `cde0bbc` から）。

## 1. 操作

| | PC | スマホ |
| --- | --- | --- |
| 挟む | <kbd>E</kbd> を押している間（小石・貝殻・重い石と同じ） | 「挟む」ボタンを押している間 |
| 引っ張る | 挟んだまま <kbd>S</kbd> などで穴から離れる（<kbd>Shift</kbd> = 急に強く引く） | 挟むを押したまま、左のスティックで下がる（2 本の指を同時に） |
| 離す | <kbd>E</kbd> を離す（体は穴へ戻っていく。押したまま近づけば挟み直せる） | 指を離す |

- 巣穴のそばの <kbd>E</kbd> は、以前は「調べる / 引っこ抜く」が優先だった。いまは常に「挟む」。スマホの「調べる / 引っこ抜く」ボタンは無くした。
- 「調べた」（`progress.flags['burrow.examined']`）は、初めて触角を挟んだときに立つ（従来どおり保存の印。触角の案内の「？？？」の表示に使う）。
- 巣穴のそばで挟むを押している間は、カニが鋏の側を穴へ向け直す（横歩きで横を向いたままでも届く）。
- 案内：触角が見えている近くでは「E 挟む：見えている触角」（ハサミが届かなければ「もっと近づいて…」。届くかは挟む判定と同じ `GrabSystem.hint`）。

## 2. 仕組み（`AquaTug.ts`・`AquaGrab.ts`）

- 穴から出ている体を「穴の口を通る 1 本の軸」で表す。軸は引く向きへ曲がる（真上から最大 66°、方位へは 2 rad/秒 = 穴の縁にこすれる）。
- 挟んだ所（触角・頭。見えている部分のうち鋏に近い点）を、**小石と同じ `clawSpring`**（ばね・減衰・握る力の上限）で鋏の構えにつなぐ。
  反作用は小石と同じ `CrabInput.tow`（引き戻される・強く張るほど下がる速さが落ちる）。鋏の見た目は CrabRig の IK でつかみ点を挟む。
- 生き物の体：つかみ点は軸に沿った質点。体の伸びのばね（上限 8 cm）と内部の減衰。体の張力が「踏ん張り」を越えた分だけ体が滑り出る（引き出し量 ext が増える）、
  下回れば生き物が体を引き戻す。横に引いた分は穴の縁の摩擦として踏ん張りに足す。
- 抵抗の段階（ext で決まる）
  - 最初（〜0.3）：小刻みに震え、短く小さく引き戻す。
  - 中盤（〜0.72）：大きく引き戻す（0.45 秒）→ 力が抜ける（0.8 秒、踏ん張り 0.65 倍・滑り出し 2 倍 = 寄せどき）。
  - 終盤（〜0.9）：激しく震え、強く短く何度も引き戻す。穴の縁の砂が崩れる。
  - 0.9 から踏ん張りが急に 0.2 倍へ抜け、一気に滑り出て抜ける（スポン）。
  - 長く強く張っていると疲れる（踏ん張り最大 0.65 倍まで下がる）＝粘れば必ず抜ける。
- 滑り（`GrabSystem`）：握る力を越えて引き続けると滑る。越え方は 2 通り。急に強く引く（走って引く等。頭打ち前のばねの力 / 握る力）、
  暴れている間に強く張っている（張力 × 暴れる強さ / 握る力）。緩めればすぐ下がる。滑りそうな間は鋏が震え、印が赤くなり「引きすぎ！ ゆるめて」と出る。
- カニ：引っ張っている間は穴へ向き、体の中心は穴の口から 0.4 より近づかない（引き戻されても穴の上に乗らない）。壁には張り付かない。
  抜けた瞬間、張力に応じた勢いで後ろへ跳ねて転ぶ（0.9 秒、体を後ろへ倒し脚をばたつかせる。この間は操作を受け付けない）。

## 3. 見た目・演出

- 体の線は穴の口を通り、穴の外の部分は引く向きへ傾く。穴の中の部分は描画（`creatureVertex` の BUDDY）で真下へ曲げる（砂から突き出さない）。
- 伸びは腹の節の継ぎ目だけで表す（各節は固いまま。体の一部だけが引き伸ばされない）。緩めると縮む。
- 同期：生き物が引き戻すたびに穴から泡・カメラが穴の方へ少し引かれる・カニの体が前へ揺すられる。滑り出ている間・終盤・横に引いた間は穴の縁の砂がこぼれる。
  強く張って下がる間はカニの足もとで砂を蹴る。抜けた瞬間は砂煙・泡・砂の崩れ・カメラの反動・カニの転倒（スマホは対応端末で振動）。
- 手応えの印（ゲージは出さない）：つかんだ所の輪（張りの強さで太さ・大きさ、色 = 張っていない / 踏ん張られている / 出てきている / 滑りそう）、
  引く向きの矢印、短い言葉（「暴れている！」「力が抜けた！」「出てきた」「もう少し！」「引きすぎ！ ゆるめて」、1 秒張らずにいると「後ろへ下がって引っ張る」）。
- カメラ：挟んでいる間は注視点を穴の方へ寄せ、少し上から見下ろす（後ろからでもカニの体の向こうの生き物が見える）。

## 4. 従来の長押し方式との違い

| | 従来（M1） | 2.0 |
| --- | --- | --- |
| 始め方 | 巣穴のそばで E =「調べる」→ 離してから長押し | 見えている触角を E / 「挟む」で挟む（小石と同じ操作・同じ判定） |
| 進み方 | 押し続ければ約 0.6 秒で必ず抜ける（速さが波打つだけ） | 押しているだけでは抜けない。下がった距離・向き・張力で進む（自動検証：まっすぐ下がって 4〜6 秒） |
| カニ | 穴から 0.6 の所に固定され、移動の入力は使わない | 自由に動ける。重いほど遅くなり、生き物に穴の方へ引き戻される |
| 向き | 関係なし | まっすぐ後ろが速い。斜めは遅い（約 1.4 倍）。穴のまわりを回るだけでは抜けない |
| 抵抗 | 進み具合の速さが周期的に変わるだけ | 段階ごとの震え・引き戻し・力が抜ける隙・疲れ・最後に抵抗が抜ける |
| 失敗 | 離すと戻るだけ | 離すと戻る（挟み直せる）。暴れている間に強く引く・急に引くとハサミが滑る |
| 体 | 位置が上がるだけ | 傾く・節の間が伸び縮みする・穴の中は真下へ曲がる |
| 抜けた後 | 尻もち（速度を与えるだけ） | 張力に応じた勢いで後ろへ転ぶ（体を倒す見た目・操作不能 0.9 秒）、カメラの反動 |
| スマホ | 「調べる / 引っこ抜く」の専用ボタン（長押しの輪） | 専用ボタンなし。「挟む」+ スティックの 2 本指 |
| 表示 | 進み具合のゲージ | ゲージなし。張りの輪・引く向き・短い言葉 |

- どの遊び方でも、カニが地形の中に入ったフレーム 0、ガラスの外 0、穴の口への最接近 0.40（下限どおり）。抜けた後の仲間：着地・同行 8 秒・自由生活 6 秒で固体の中 0、
  ガラスの外 0、瞬間移動 0。
- 振動：まっすぐ下がる間の張力の 1 フレームの変化は最大 0.14（握る力に対する割合）。最初は 0.6 前後の跳ねがあり、原因はカニの踏ん張りの見た目の揺れ（約 30 Hz）が
  鋏の構えを通ってばねの減衰に入っていたこと。生き物へ渡す鋏の構えを 33 ms でならして解消した（描く鋏は IK でつかみ点を挟むので見た目は変わらない）。

## 6. 気づいたこと・残り

- ハサミは右側にあり腕の長さ（付け根から 0.33）までしか届かないので、挟めるのは体の中心が穴から約 0.5 以内のとき。届かないと案内が「もっと近づいて」になる。
- 自動検証は実時間ではなく 1/60 秒刻みで進めた値。実機（特に iPhone）での手触り・振動（iPhone の Safari は `navigator.vibrate` 非対応）は未確認。
- `TouchControls` の `act` ボタン（`Input.touchAct`）は水槽ゲームでは使わなくなったが、汎用の部品として残した。
- `buddy_helpers.js` の `pullFlow` は従来の長押し用（使えない旨を先頭に書いた）。`grab_shots.js` は `.act` が無くても動くようにした。
- 生き物は 1 種（スナモグリ）。種ごとの抵抗・節ごとの質点（ゴカイ等）は `TugSpec` を増やして対応できる形にしてある。
