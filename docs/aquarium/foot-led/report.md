# 第 7 段階：接地主導の移動（崖・段差を降りる）

接地 IK（第 4・6 段階）の脚の接地を、見た目と速さだけでなく**胴体の移動そのもの**へ返す最初の段階。対象は「崖・段差を降りる」。
カニが縁へ来ると、先頭の脚が縁の下の足場を探し、下の足場に脚が掛かるまで胴体は縁から出ない。掛かったら脚に支えさせて
胴体を一定の速さで下ろす。高い崖は側面へ脚を掛けて壁登りへ移り、そのまま降りる。足場が見つからなければ縁で立ち止まり、
押し続けると踏み出して落ちる（水中は沈む）。

「🔊 音と設定」→「歩き方」で **接地主導（新・既定）／接地 IK（移動は従来）／従来（歩行周期）** を切り替えて比べられる。

## 結論

- **崖を降りる動作は成立した。** 低い段差・高い崖・斜めの縁・流木の側面・水面をまたぐ高台の縁で、従来の「縁から転がり落ちる」
  が「縁で止まる → 脚を下へ伸ばす → 脚に支えられて下りる（高い崖は岩肌に張り付いて降りる）」に変わった。空中にいるフレームは
  大きく減り（高い崖 73 → 12、低い段差 14 → 0〜6、高台の縁 54 → 0）、陸上の落下の速さの最大は 9.7 → 1.6 / 秒。
- **従来の移動は損なっていない。** 接地 IK（移動は従来）を選んだときの数値は公開版（main）と完全に一致（9 か所の接地 IK の検証）。
  接地主導でも、縁の無い所の歩き・ダッシュ・方向転換・壁登り（29 場面）・天井歩き（6 か所 + ガラス・管）・穴掘り・盛り土・
  挟む・水草・エビ・スマホの入力（21 項目）・保存と復元は公開版と同じ結果。性能（1 フレームの更新）の差は計測のばらつきの範囲。
- **悪化した点**：縁で待つぶん、崖を降りる所要時間は長くなる（滝の上の崖の往復の平均の速さ 1.89 → 0.92〜1.03 / 秒。
  従来は飛び降りていた）。低い段差を降りた直後に、岩がカメラとカニの間に入ってカメラが一度寄る（既存の遮蔽の動き）。
- 全方向移動（床・壁・天井を脚の接地から切り替える）は、この仕組みの延長で作れる見込み。推奨する次の範囲は末尾。

## 仕組み（`src/aquarium/CrabLedge.ts`・`CrabController.ts`・`CrabFeet.ts`）

### 1. 縁を見つける（`scanLedge`）
歩いている向きの前方を 0.08 ごと（0.08〜0.48）に真下へ探り、0.05 進むごとに 0.075 より大きく下がる所（約 56° より急＝
歩いては下りられない所）を縁とする。下の足場の高さは、縁の先 0・0.3・0.6 のいちばん低い所（丸い岩の側面の途中を拾わない）。
縁の外向きは、縁の少し外・下の点の距離関数の勾配の水平成分（斜めに近づいても縁に垂直な向きで止める）。
縁が見えていない間は 3 フレームに 1 回だけ探す（ダッシュでも 3 フレームで 0.22 しか進まない）。

### 2. 種類
| 種類 | 条件 | 降り方 |
| --- | --- | --- |
| 段差 | 下まで 0.8 以下 | 縁の角に乗って少し身を乗り出し（はみ出し 0.14 まで）、先頭の脚を下の足場へ。2 本以上掛かったら胴体を脚で支えて下ろす |
| 崖 | 0.8 より高く、縁のすぐ下の側面が登れる面 | 縁で止まり、先頭の脚を縁の下の側面へ。掛かったら縁を回り込む道（`descentPath`）をたどって側面へ張り付き、壁登りのまま降りる |
| 足場なし | どちらでもない | 縁で止まる（はみ出し 0.03 まで）。0.6 秒押し続けたら踏み出す |

### 3. 胴体は脚の接地で動く
- **縁へ向かう速さを抑える**（`ledgeGate`）：縁に垂直な成分だけを、はみ出しの上限までの距離 × 7 に抑える（縁に沿う向き・
  離れる向きはそのまま。斜めに近づけば縁に沿って歩ける）。段差で先頭の脚が下の足場に 2 本以上・接地 4 本以上なら抑えない。
- **脚で支えて下ろす**（`ledgeSupport`）：縁を越えて床に触れていない間、下の足場に脚が 2 本以上掛かっていれば 1.0 / 秒で
  下ろす（吸着で一気に落とさない・重力を掛けない）。身を乗り出しているだけなら高さを保つ。踏み替えの間（接地 2 本以上）は
  0.25 秒まで待ち、それより長く支えが無ければ落ちる（掘って足場が消えたとき）。
- **胴体だけが先へ浮かない**：下に隙間がある間は、縁の外へ進む速さを隙間 0.3 で 0.3 倍まで落とす。
- **崖の側面へ移る**（`startDescentClimb`）：床の向きのまま張り付き、道の進み具合に合わせて体を床 → 側面へ回す（縁の上で
  急に回らない）。スティックの写し方は床の向きから決めて面と一緒に回すので、押し続けた向き（崖の外）は「壁から離れる = 下」
  になり、そのまま降りる。下の床で従来の壁登りの判定で歩きへ戻る。
- **脱出**：ジャンプはいつでも効く（縁の状態は捨てる）。後ろ・横へは抑えない。押すのをやめれば縁で立ったまま。

### 4. 脚（`CrabFeet`）
- 縁の手がかり（`LedgeHint`：外向き・縁の点・種類・押しているか）を `CrabRig` から受け取る。
- **先頭の脚**（理想の位置が縁の近く・外）で、まだ縁より下に掛かっていない脚は、縁の下（段差 = 縁の外 0.16・下 0.06 から
  真下へ、崖 = 縁の外 0.05・下 0.16 から側面へ）を探す。縁より下の足場だけを受け付け、点は従来どおり「理想からの距離 +
  面の向きのずれ」（＝平らで安定した足場を選ぶ）。届かなければ 0.25 秒待って探し直す。立って押している間に初めて届かなかった
  脚は、縁の外へ伸ばして宙で構える（探っている動き。同時に 2 本まで、構えた脚はそのまま＝震えない）。
- **押すのをやめたら探さない**（止まっている間の不要な踏み替えを出さない）。
- 縁より下に掛かった脚の数（`down`）・側面に掛かった脚の数（`face`）を支えとして返す。
- 胴体を脚で下ろしている間（上下に動いている間）も歩行の周期を進め、組ごとに踏み替える（縁の手がかりがあるときだけ。
  接地 IK（移動は従来）の歩き方は変えていない）。

### 5. 診断（「接地の診断を表示」・?diag）
接地主導のとき、縁（橙の線と外向きの矢印）・縁より下に掛かった足先（橙の輪）と、
「縁 種類 高さ はみ出し 下の脚（側面）支えて下ろす / 踏み出す / 待つ 秒」を左下に出す。

## 全方向移動への拡張：課題と推奨
### 試作で分かったこと
1. **「脚が掛かってから体を動かす」は、速さの上限（縁に垂直な成分）＋脚での支え（下ろす速さ）＋面の切り替え（壁登りの道）の
   3 つで作れた。** 体の当たり判定（球と距離関数）は変えずに済んだ。全方向でも、球の当たり判定は残し、「どの面へ移るか・
   いつ移るか」を脚の接地で決める形がよい。
2. **面の向きの判定が脚の面とずれる。** 斜めの崖では、縁より下に掛かった脚の面は「側面」の向き（外向き・急）にならず、
   側面の本数の条件が満たされたり満たされなかったりした（下に掛かった脚の本数でも認めるようにして安定）。全方向では、
   脚の面の向きを 1 本ずつ見るより、**掛かっている足先の組から面（重心と法線）を求めて**判定するのがよい（`bodyPose` の
   Newell の法線をそのまま使える）。
3. **縁を探す処理は前方の真下だけ。** 横・後ろへ漂って縁を越えると従来どおり落ちる（今回は押している向きだけ）。
   全方向では、移動の向き＋体の向きの 4 方向を間引いて探すか、脚の探索の失敗（足場なし）を縁の手がかりにする。
4. **壁登りへ移る道（`descentPath`）は折れ線で固定の速さ。** 脚の接地を待たずに進む（脚は遅れて踏み替える）。
   全方向では、道の進み具合も脚の接地（前の脚が次の面に何本掛かったか）で止める・進めるようにしたい。
5. **時間の決め方が数値に敏感。** 縁を 3 フレームに 1 回探す・脚の探し直しの待ちなどで、同じ入力でも「側面へ移る / 踏み出す」
   が分かれた例があった（直した後、順番を変えた 2 回で同じ結果）。全方向では、判定に**ヒステリシス**（移る条件と戻る条件を分ける）
   を入れておく。
6. **カメラ**：崖を降りる途中・降りた直後の遮蔽の寄りは既存の動きのまま。張り付いた面の向きに合わせた
   カメラの高さの調整（`AquaCamera` の climbW）を、縁を越える道の間にも効かせる余地がある。

### 推奨する次の実装範囲（第 8 段階の候補）
1. **前の脚を壁に掛けて登る**：今の「壁へ押し続けたら 0.1 秒で張り付く」を、「前の脚が壁に 2 本掛かったら張り付き、体を
   脚の面へ回す」に置き換える（崖を降りる仕組みの逆向き。`LedgeHint` を「壁」にも広げる）。
2. **床・壁・天井の切り替えを脚の面から**：張り付いている面の向き（`climbN`）を、体の球の周りの距離関数の平均ではなく、
   掛かっている足先の組の面へ寄せる（壁 → 天井の回り込みで、前の脚が天井に掛かってから体を回す）。
3. **足場が消える・崩れる**：張り付いている面で、掛かっている脚の足場が掘られたら、残りの脚の面で支えるか離れる
   （今は壁・天井で 2 本未満が 0.8 秒続いたら離れる）。
4. 上の 1〜3 を、今回の `ledge_test.js` と同じ形（同じ場所・同じ入力、従来と比べる）で検証する。複雑な岩肌に 8 本でしがみつく
   （凹凸の多い面で全部の脚が別々の面に掛かる）は、2 の後に。

## 実装の補足
- 既定の歩き方は「接地主導」。ただし、これまでに設定を変えたことのある人は、保存された歩き方（多くは「接地 IK」）のまま
  （設定は `ppp-aquarium:ui` にまとめて保存され、変えた項目以外も保存されているため）。設定で「接地主導」を選べば切り替わる。
- 縁の状態は保存しない（瞬間移動・復元で捨てる）。
- 管の中・濾過槽・水槽の外・泳ぐ・掘る・生き物を引っ張る・転んでいる間は、縁の扱いをしない（従来どおり）。
