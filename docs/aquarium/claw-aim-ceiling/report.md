# 第 2 段階：ハサミの操作と天井歩きの改善 — 報告

ブランチ：`feat/aquarium-claw-aim-ceiling`（`main` = `ca37833`、第 1 段階のマージの後から）。検証は Chromium（Playwright）のスマホの模擬
（390×844 / 844×390・タッチ）と PC（1280×800）。**iPhone の実機では確かめていない**（6 章）。

## 1. スマホの「挟む」スイッチ

| 要件 | 実装（`src/ui/TouchControls.ts`・`src/game/Input.ts`・`main.ts`） |
|---|---|
| たたくと閉じ、もう一度で開く | `Input.touchGrabLatch` を押すたびに切り替える。指を離しても閉じたまま |
| 状態を明確に | 閉じている間はボタンが明るく光り（外側の光の輪）、文字が「離す」、上に錠の印、`aria-pressed="true"` |
| 閉じたままジャンプ・ダッシュ・移動・視点 | スイッチは指を持ち続けないので、同じ指でほかのボタンを押せる。押した指をそのままずらすと視点を回せる（従来どおり） |
| 回転・アプリの切り替え・指の取り消し | `Input.releaseAll`（回転・裏へ回る・取り消し）は指だけを終わらせ、スイッチは変えない。ハサミの側が開いた（滑った・抜けた・水流に乗った・瞬間移動・R キー）ら、スイッチも開く（ボタンとハサミが食い違わない） |
| PC の E | 従来どおり押している間だけ挟む。押したままマウスを動かすと腕の向きを変えられる（掘るの F と同じ扱い） |

## 2. ハサミの狙いやすさ

| 要件 | 実装 |
|---|---|
| 体の向きだけに頼らず腕を向ける | `CrabRig.armAim`（x = 右, y = 上）で構えた鋏の先を右 0.13・上 0.10・下 0.12 までずらす（IK で腕が追う）。入力は `Input.armAim()`：ゲームパッドの右スティック用の `armAimExtra`（第 3 段階で使う）→ E を押したままのマウス。動かしている間は鋏を構えて見せる |
| スマホの狙いの補助 | `GrabSystem.near`：体の中心から 0.8 以内・体の前の側の、いちばん近い挟める物。**挟むを押している（閉じている）がまだ挟んでいない間だけ**、体（鋏の側）をその物へ向け、腕をその高さ・横へ向ける。届けば挟む（閉じたまま空なら届いた瞬間に挟み直す従来の仕組み）。押していない間は向きを変えない・挟まない |
| 挟める位置の案内 | `#grab-cursor`：届く物のつかみ点に明るく脈打つ輪（スマホは「挟める」）、近いが届かない物に薄い点線の輪。PC の「E 挟む：名前」も従来どおり |
| 補助が強すぎない | 体を向けるのは閉じている間だけ・前の側の物だけ。前へ歩かせることはしない（届かなければ自分で近づく） |
| 触角の当たり判定と案内 | 生き物は物より 0.07 遠くから挟め、腕を伸ばしきる所（0.35）まで届く。巣穴の前の距離 0.47 → **0.53 まで**挟めるようになった（0.56 は届かない）。触角にも輪が出る |

## 3. 小石・貝殻を自由に挟む（`src/aquarium/AquaDecor.ts` 新規）

- 景色の小石 **520 個**と、水槽の中の発見物の貝殻・巻貝 **9 個**（合わせて 529 個）を、どれでも挟めるようにした。
- 負荷：ふだんは 1 つの大きな景色のメッシュのまま。それぞれに楕円体の影（`Prop`。`PropSystem.props` には入れない）を持たせ、挟む候補と
  狙いの補助の候補としてだけ調べる（遠い物は距離だけで飛ばす）。**鋏を閉じた瞬間にその物だけ物理の物にする**。物理の物の間は景色の
  メッシュのその物の頂点と法線を、物の位置・向きで書き直す（描画の部品は増やさない）。止まって・挟んでいない・カニから 2.6 より遠い物は
  物理の物から外す（いまの位置のまま景色に戻る）。物理の物は最大 28 個。
- 掘って根元の砂が無くなった景色の小石は、以前は消していたが、**物理の物にして穴へ落とす**（上限を越えたときだけ従来どおり消す）。
- 重さは大きさ（楕円体の体積）で決める：小石（< 0.5）は持ち上がる、石・大きな石は持ち上がらず引きずる・動かない（カニの方が止められる）。
- 岩・流木（`FixedGrip`）：押した瞬間に何も届かず岩・流木の面が届くときだけ、その点をつかむ。物は動かず、ばねの反作用でカニが引き戻される
  （離れようとしても動けない・ぶら下がれる）。走って強く引くと外れる。閉じたまま歩いている間は岩をつかまない（勝手につかまない）。
- 物の位置は保存しない（従来の挟める物と同じ。読み込み直すと元の場所）。

## 4. 天井歩きの安定化（`src/aquarium/CrabController.ts`）

| 要件 | 実装 |
|---|---|
| 接触面の法線を安定して評価 | `surfaceNormal()`：体の中心と、面に沿って 0.12 離れた 6 点の法線の平均。中心の法線とそろう点の数（cover）も返す |
| 小さな出っ張りで逆さにならない・張り付く意思 | 空中・水中から天井へ：平均した法線で判定し、狭い面（cover < 4）は張り付かない。ジャンプを押していれば 0.1 秒、**移動入力だけなら 0.3 秒**触れ続けたら（以前はどちらも 0.1 秒・中心の法線だけ）。床から張り出した面へ張り付くときも平均した法線と cover。張り付いている間も、狭い出っ張りでは張り出した向きへ体を起こさない |
| 壁 → 天井で自然に姿勢を変える・向きが跳ねない | 面の向きを変える速さを 1 秒 6 ラジアンまでに（1 フレームで跳ねない）。目標は平均した法線 |
| 天井の上で画面基準の向きが分かる | `#climb-cue`：張り出し・天井（法線の y < −0.3）にいる間、カニの中心から「スティック↑」で進む向きの矢印を出す |
| 面が切り替わる瞬間にスティックの向きが反転しない | 従来の仕組み（入力の写し方を面に貼り付けて回す）をそのまま使う。目標の向きが平均化・速さの上限でなめらかになった |

途中で「張り出しへは押し続けたときだけ回り込む（それまで体の向きを保つ）」を試したが、位置は面に沿って回り込むのに体の向きが遅れ、
スティックを離すと壁の向きのまま止まった（崖の抜け道で天井へ着かなくなった）ので、やめた。

### 天井歩きの回帰（`ceiling_test.js`）

| 場所 | 天井まで（前回の報告 → 今回） | 止まったときのずれ | 前・後 |
|---|---|---|---|
| 倒木の中（水中・流木） | 0.82 → 0.82 秒 | 0.07 | 1.05 / 1.05 |
| 洞窟のトンネル（水中・岩） | 1.17 → 1.17 秒 | 0.07 | 1.05 / 1.05 |
| 掘ったトンネル（水中・砂） | 0.82 → 0.82 秒 | 0.07 | 1.05 / 1.04 |
| 掘ったトンネル（陸上・土） | 0.88 → 0.90 秒 | 0.08 | 1.22 / 1.21 |
| 崖の抜け道（陸上・岩・狭い） | 0.73 → 0.73 秒 | 0.08 | 反対側の壁を伝って床へ（前回と同じ） |
| 倒木の中・ジャンプを押したまま離れる | 0.82 → 0.82 秒 | 0.07 | 1.05 / 1.05 |

どの場所もジャンプで離れて床に着地、カメラが固体の中 0、面を失って落ちた 0。

### 狭い出っ張り

水槽の中で、体の中心が面から体の半径の所にあり、中心の法線が下向き（y < −0.3。以前の判定なら空中から張り付く）点を 270 個集めた：
平均した法線では **18 個（6.7%）が張り出しではない**（流木・岩の縁。平均すると上・横向き）と判定され、張り付かない。
広い天井（洞窟の天井 2 か所）では、移動入力でもジャンプでも、空中から張り付いた（`grabsAir`）。

## 6. iPhone の実機でしか確かめられないこと（公開後の確認事項）

1. 挟むスイッチ：たたくたびに確実に切り替わるか（二重に反応しないか）、閉じたまま別の指でジャンプ・ダッシュ・スティック・視点ができるか、
   回転・アプリの切り替えの後もボタンの見た目とハサミが一致するか
2. 輪（挟める・近い）が見やすいか、狙いの補助で勝手に向きが変わる感じがしないか
3. 触角が以前より挟みやすいか
4. 景色の小石・貝殻を挟んで動かしたときの見た目（物理の物へ切り替わる瞬間に跳ねないか）と、フレームの時間
5. 天井：小さな出っ張りで裏返らないか、天井の矢印が分かりやすいか、張り付きにくくなりすぎていないか（移動だけで天井に張り付くまで 0.3 秒）

## 7. 文書とコードの食い違い・残る問題

- `docs/aquarium/tools/grab_shots.js` は、スマホの「挟む」を押し続ける前提（以前の仕様）。今回の切り替え式では、押している間の動きを
  撮る部分が意図と違う（使うときは 1 回たたく形に直す）。今回は直していない。
- `Input.touchGrab`（押している間）は使われなくなったが、ほかの道具の互換のため残した。
- 景色の小石は、以前は「挟める物と見分けがつくように」挟める物を明るい黄土色にしていた（`AquariumBuild` の注釈）。景色の小石も挟めるように
  なったので、その区別の意味は無くなった（色は変えていない）。
- 物理の物になった景色の小石・貝殻と、置いた所から動かした物の位置は保存しない。
- 発見物の貝殻・巻貝のうち、水槽の外（濾過槽・部屋）の物は挟めない（挟む操作が水槽の中だけのため）。
- 岩・流木をつかんでいる間、歩いて離れようとしても外れない（走ると外れる）。離すにはもう一度たたく / E を離す。
