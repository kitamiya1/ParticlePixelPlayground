# 第 3 段階：水草をかき分ける

密集した水草の中でも、カニが茎や葉を実際に押し分けながら進めるようにした。森の密度・景観はそのまま（植物は 1 本も減らしていない）。

## 仕組み
- **植物の表**（`AquariumBuild.ts` の `PointsOut`）：植えるとき（`anchor`）に植物の番号・根元・高さ・種類を付ける。
  テープ状の葉は 1 枚、有茎草は 1 本、汀線の草は 1 本、シダ・葉の広い草は 1 株が 1 つの植物（計 1,329）。
  絨毯・陸の苔・岩や流木の苔は小さいので曲げない（番号 −1）。円盤ごとの植物の番号は `iPlant`（インスタンスの属性）。
- **曲げ方**（`SurfelRenderer.ts` の `PLANT_BEND`）：植物ごとの「押された量（根元に対する水平のずれ）・押された高さ・震え」を
  浮動小数のテクスチャ（64 × 21、1 画素 = 1 本）から読み、根元は固定、押された高さまで 3 次の曲線で立ち上がり、
  そこより上は種類ごとの割合まで起き上がる（水の中の葉先）。曲がった分だけ低くなる（長さを保つ近似）。既存の水流の揺れはその上に足す。
- **方式**（「🔊 音と設定」→「水草のかき分け」。`AquaPlants.ts`）
  - **しなる（dyn・既定）**：押す球（カニの体 = 脚の広がり 0.42、挟んでいる物・動いている物）の近くの植物だけ（格子 0.8 で探す）、
    CPU でばね + 減衰を進める。押されている間は押し出した位置を保つ（止まっていても分かれたまま）。離れると種類ごとの硬さ・
    水の抵抗（減衰）で戻る。進む向きの前にある草は左右へ分ける。勢いよく分け入ると跳ねて揺れ、しばらく震える。
  - **GPU だけ（gpu）**：状態を持たず、頂点シェーダーが押す球（とカニの通った跡の球 4 つ。古いほど小さい）から毎回求める。
    CPU は使わないが、戻りの遅れ・跳ね・左右への分け方・見通しの線は無い（比較用）。

| 種類 | 硬さ k | 減衰 ζ | 押された所より上に残る | 曲がりの上限 |
| --- | ---: | ---: | ---: | ---: |
| テープ状の葉 | 4.5 | 0.62 | 45% | 0.75 |
| 有茎草 | 9 | 0.70 | 80% | 0.5 |
| シダ | 16 | 0.80 | 100%（株ごと） | 0.3 |
| 葉の広い草 | 18 | 0.80 | 100% | 0.25 |
| 汀線の草 | 12 | 0.65 | 90% | 0.3 |

### 見失い対策（必要最小限）
体のまわりを分けるだけでは、**カメラとカニの間にある背の高い葉**（カメラのすぐ前の葉）が残り、森の中ではカニがほとんど見えない
（下の表の dyn-body）。そこで、**カメラ → カニの見通しの線（半径 0.32）にかかる草も、線と直角の向きへそっとよける**
（描画で抜く・透かすのではなく、草が分かれて見える。カニの手前 0.4 は体が分ける）。dyn のときだけ。

## 確認（`tools/plant_part_test.js`・`plant_part_shots.js`。PC 960×600）

### カニの見え方（カメラ → カニの体の中心と上下左右 0.12 の 5 本の線のうち、水草の円盤に遮られる割合。3 秒歩く間の平均）
| 場所 | 曲げない（変更前） | GPU だけ | ばねだけ（dyn-body） | **しなる（dyn）** |
| --- | ---: | ---: | ---: | ---: |
| 水草の森の通路を横切る | 0.68 | 0.70 | 0.69 | **0.22** |
| 有茎草の茂み | 0.57 | 0.56 | — | **0.10** |
| 森の小部屋 | 0.37 | 0.36 | — | **0.00** |

### 動き
| 項目 | 結果 |
| --- | --- |
| 止まって 2 秒：体と重なった草（5 本）の押された量 / 必要な量 | 最小 0.9・平均 1.49（分かれたまま） |
| 森から離れたとき：押された草（48 本、最大 0.59）が半分戻るまで / 止まるまで | 0.87 秒 / 4.6 秒 |
| 歩き（1.7 / 秒）とダッシュ（3.2 / 秒）で分け入ったときの震えの最大 | 0.32 → 0.62（勢いよく揺れる） |
| 小石を挟んで森へ運ぶ | 挟んだ物も押す球になり、草を分ける |
| 1 フレームの計算時間（dyn、森の中） | 平均 0.03〜0.06 ms・最大 0.2 ms（植物 100 本前後を計算） |

- 性能（`perf_quick.js`、交互に 2 回）：森の中で 更新 + 描画の命令 off 1.47 / gpu 1.64 / dyn 1.66 ms、実際のフレーム間隔はどれも 15〜16 ms
  （画面の更新で頭打ち）。スマホ相当（390×844）の森でも off 1.81 / dyn 1.71 ms。頂点ごとのテクスチャ読みの GPU 負荷は測れていない。
- 保存・復元 OK（かき分けは保存しない）。本番ビルド OK。

## 未確認・残る問題
- **iPhone 実機は未確認**（頂点シェーダーでの浮動小数テクスチャの読み。WebGL2 の Safari なら使える想定）。
- 絨毯状の水草・苔は曲げない（カニが上を歩いても押されない）。
- 植物の茎は根元から真上の線として当たりを計算するので、大きく傾いた葉は、見た目より少し外れた所で押される。
- 見通しの線でよける草は「カメラの前の草が自然に分かれる」ように見えるが、カニを見ていない（カメラを回している）間も分かれる。
