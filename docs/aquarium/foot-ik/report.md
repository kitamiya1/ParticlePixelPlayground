# 第 4 段階：接地 IK とプロシージャル歩行

8 本の歩脚がそれぞれ地形の上に実際の足場を探して足先を置き、置いた足先は世界に固定する（胴体が動いても滑らない）。
胴体の高さ・傾きは接地している足先から決め、脚の支えは移動の速さ・壁 / 天井の張り付きにも返す。床・斜面・壁・天井・張り出しを
同じ探し方で扱う。従来の歩き方（歩行周期）と「🔊 音と設定」→「歩き方」で切り替えて比べられる（既定は接地 IK）。

参考：[majidmanzarpour/threejs-procedural-spider](https://github.com/majidmanzarpour/threejs-procedural-spider)（MIT。
足場を探して踏み替える・となりの脚が踏み替え中は待つ・接地した足先から胴体の面を決める、という考え方を参考にした。
コードは使っていない。参考は真下へだけ探し、天井は扱わないので、このカニの距離関数の地形・壁・天井に合わせて作り直した）。

## 実装（`src/aquarium/CrabFeet.ts`、`CrabRig.ts`、`CrabController.ts`）

### 脚ごとの状態
接地している所・面の向き・有効か（面の上にあるか）・踏み替え中（元 / 行き先 / 進み具合）・次の足場の候補・付け根・届く長さ・伸び・
理想の位置とそこからの距離・材質。

### 足場の探し方
- 理想の位置 = 体の座標の休みの位置 + 進む向きへの先読み（速さ × 踏み替えの時間）。その 0.16 上（体の上の向き）から、
  真下・斜め下（外へ / 進む向きへ / 内へ / 後ろへ）・進む向き（壁）・外向き・上・斜め上（張り出し・天井）の 9 方向へ、
  `contactSolid` を少しずつ進めて最初の面を探し、5 回の二分で面の上に置く。面の向きは `contactNormal`、材質は `surfaceMaterial`。
- 評価：脚の届く範囲（付け根から l1 + 下の節の 98% 以内）・理想の位置から 0.33 以内・体の上と反対を向く面は張り付いている面と
  合うときだけ・床（上向き）ならどの材質でも、壁 / 天井は登れる材質（砂・土・岩・流木）だけ（ガラス・アクリル・管は従来どおり掛けない）。
  点 = 理想からの距離 + 面の向きのずれ。
- 1 フレームに探すのは 4 本まで（フレームに分散）。

### 足先の固定と踏み替え
- 接地している足先は世界に固定（`CrabRig` が根の逆行列で根の座標へ直し、既存の 2 関節 IK `solveLeg` で解く）。
- 踏み替える：理想の位置から 2 × 速さ × 踏み替えの時間 以上ずれた・伸びが 92% を超えた・足場が消えた（足先の所の距離関数が
  空になった：掘った・崩した）・止まっていてもずれたまま 0.35 秒（必要な脚だけ踏み直す）。
- 順番：急ぐ順。となりの脚（同じ側の前後・反対側の同じ脚）が踏み替え中なら待つ（伸びすぎ・足場が消えた、は待たない）。
  同時に踏み替えるのは 4 本まで。結果として左右交互の 4 本ずつに近い順になる。
- 踏み替えの時間 = 0.12 / (速さ + 0.25) 秒（ゆっくり 0.18 秒・歩き 0.05 秒・ダッシュ 0.035 秒）。前の足場から次の足場へ、
  ゆっくり加速・減速しながら運び、面の外向きへ sin で持ち上げる（高さ 0.045〜0.075）。

### 脚の接地に基づく胴体
- 接地している足先の重心の高さ（体の上の向き）で胴体を上下（±0.07）、足先の多角形の法線（Newell の方法）と体の上の中間へ
  胴体を傾ける（22° まで）。異なる高さの足場に立つと自然に傾く。
- 脚が伸びきって踏み替えられない間は速さを落とす（伸び 100% を超えた分 × 4、最小 0.5 倍）。接地している脚が 3 本未満なら 0.6 倍。
  脚が届かない所へ胴体だけが先へ行かない。
- 壁・天井：張り付いている面に掛かっている脚が 2 本未満の状態が 0.8 秒続いたら、支えを失って離れる（落ちる・沈む）。
- 空中・遊泳・沈降・転倒の間は従来の脚の動き（着地したら全部の脚をその場の足場へ置き直す）。掘っている間の前脚も従来の動き。
- 胴体の当たり判定（球）は変えていない。根の補正は見た目だけで、当たりと食い違うのは高さ ±0.07・傾き 22° まで。

### 診断（「🔊 音と設定」→「接地の診断を表示」・?diag）
足先（接地 = 緑 / 足場が無い = 赤 / 踏み替え中 = 水色）・次の足場の候補（黄の ×）・付け根から届く範囲（円）・付け根 → 足先の線、
左下に 接地している脚・面に掛かっている脚・伸びの最大・速さの割合・踏み替えの回数・探索の回数と時間。

- 速さ = 移動の入力を与えた間と止まった後 1 秒の平均（止まっている時間を含む）。IK でも入力どおりに進む。
- 伸びの最大が 1 を超えるのは、壁・天井へ移る瞬間（体の向きが一気に変わる）と段差を越える瞬間で、急ぎの踏み替えですぐ戻る
  （IK は届かない所へは脚を伸ばしきるだけで、足先は面の上に残る）。
- 足場を掘って消す（立ったまま下へ掘り続ける）：足場が消えた脚 8 回 → 全部の脚が新しい足場へ踏み替え、宙に残った足先 0、
  足先が面の上 97%（踏み替えの途中を含む）。
- 天井歩きの回帰（`ceiling_test.js`、6 か所 + ガラス・管）：従来とほぼ同じ（張り付くまでの時間・止まったときのずれ・前後左右・
  ジャンプで離れる）。崖の抜け道（岩のトンネル）で、後ろへ戻って縁を越えた所で脚が掛からず支えを失って 1 回離れた（想定した動き）。
  ガラス・管には張り付かない（従来どおり）。
- 性能（`perf_quick.js`、交互に 2 回）：更新 + 描画の命令 従来 1.17〜1.59 / IK 1.44〜1.74 ms（約 +0.1〜0.3 ms）。
  足場を探す 1 フレームの最大 0.7〜2.8 ms（全部の脚を置き直すフレーム）。スマホ相当（390×844）も同程度。
  フレーム間隔の差は無い。iPhone の実機では未計測。
- 保存・復元 OK（歩き方の設定は `ppp-aquarium:ui`）。本番ビルド OK。

## 既存方式との違い
| | 従来（歩行周期） | 接地 IK |
| --- | --- | --- |
| 足先 | 体の座標の決まった位置を周期で振る（地形を見ない） | 地形の上の足場に置いて固定（滑らない） |
| 凹凸・段差 | 足先が地面に埋まる・浮く | 1 本ずつ実際の高さに置く |
| 胴体の傾き | 体の中心の下の 1 つの面の向き | 足先の多角形の面との中間 |
| 壁・天井 | 体の向きに合わせて脚を広げる | 面の上に脚を掛ける。掛からなければ支えを失って離れる |
| 掘って足場が消えた | 変化なし | その脚が新しい足場を探す |
| 移動 | 入力どおり | 脚が追いつかない間は少し遅く |

## 未確認・残る問題
- **iPhone 実機・実際のゲームパッドは未確認**。
- 胴体の移動・壁への張り付き・天井への回り込みの判定そのものは、従来の `CrabController`（体の球と距離関数）のまま。
  脚の接地は、速さ・支えを失って離れる・胴体の見た目の高さと傾き、に返している。「前脚が壁に足場を見つけてから胴体を壁へ向ける」
  「足場の探索で詰まりを抜ける」は、体の向きの切り替えを脚の接地から決めるところまでは作っていない（次の段階の候補）。
- 速いダッシュ（4.4 / 秒）では踏み替えが 2 フレームほどになり、脚の動きは速い小刻みの足運びに見える。
- 流木・トンネルのように体の向きが大きく変わる所では、急ぎの踏み替えが多い（伸びの最大 1.3〜1.7）。
