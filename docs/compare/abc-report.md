## 所見

**技術的な事実（計測・画像から確認できること）**

- 性能：同じ点数で GPU 時間は C < B < A（標準視点で 2.13 / 2.75 / 2.85 ms）。C は不透明 + 深度テストで、点 1 つあたりの画素が A の正方形より小さく（円の内側だけ）断片数が A の約半分。
- 隙間：標準視点ではどの方式も空は見えない。浅い角度では面の向きに沿った円盤（C）が細くなり、空が見える画素（0.13 %）・奥が見える画素（3.2 %）が A・B より多い。
- ちらつき：移動時の変化は C が最小、A が最大。
- 小物の見え方：小道の花びら・小石は、A では画面に正対した小さな点、B・C では地面に寝た円盤・楕円になり、上から見ると面積が大きく見える（`near` の行で顕著）。

**見た目の好み（主観。技術的な優劣ではない）**

- A は粒感が強く、ディザ模様が「ドット絵らしい」質感を出す。
- B は輪郭がやわらかく、面がつながって見える。
- C は B に近い面のつながりを、深度による輪郭（奥行き差の暗線）付きで出す。浅い角度では円盤の縁が目立つ。
